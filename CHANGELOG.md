# Changelog

## 1.0.0 (2026-11-26)

- First release: 15 plugins and the all-in-one `website-dev-skills` bundle, 343 skills in total.
- All plugins renamed to the `website-dev-` scheme, with credits, licenses and NOTICE files.
- Skill descriptions fixed to pass Claude's plugin validator (max 1024 characters, no angle brackets, valid YAML).
- Marketplace file for Claude Code and claude.ai (Customize > Plugins > Add marketplace).
- Install scripts for macOS, Linux, WSL and Windows; Python validator and builder.
