## Install

- **claude.ai or desktop app:** download [website-dev-interface-guidelines.plugin](https://github.com/aiwithrakshi-dev/claude-design-skills/raw/main/dist/website-dev-interface-guidelines.plugin), then go to Customize > Plugins > Add > Upload plugin.
- **Claude Code (2.1.275 or later):** `/plugin install website-dev-interface-guidelines --marketplace aiwithrakshi-dev/claude-design-skills`
- **Claude Code (any version):** `claude plugin marketplace add aiwithrakshi-dev/claude-design-skills` then `claude plugin install website-dev-interface-guidelines@aiwithrakshi`

## Try these prompts

- Review app/page.tsx against the web interface guidelines and list every violation.
- Check my forms against the guidelines and fix what fails.
- Audit this navbar for keyboard, focus and touch-target problems.
