# website-dev-gsap

**GSAP (official GreenSock skills)** · 8 skills · part of [website-dev-skills](https://github.com/aiwithrakshi-dev/claude-design-skills)

- **Original author:** GreenSock
- **Original source:** [greensock/gsap-skills](https://github.com/greensock/gsap-skills)
- **License:** MIT (see `LICENSE` in this folder)
- **Best for:** Timelines, ScrollTrigger, pinning, SplitText and GSAP in React or Vue.

## Install

- **claude.ai or desktop app:** download [website-dev-gsap.plugin](https://github.com/aiwithrakshi-dev/claude-design-skills/raw/main/dist/website-dev-gsap.plugin), then go to Customize > Plugins > Add > Upload plugin.
- **Claude Code (2.1.275 or later):** `/plugin install website-dev-gsap --marketplace aiwithrakshi-dev/claude-design-skills`
- **Claude Code (any version):** `claude plugin marketplace add aiwithrakshi-dev/claude-design-skills` then `claude plugin install website-dev-gsap@aiwithrakshi`

## Skills in this plugin

| Skill | What it does |
|---|---|
| `gsap-core` | Official GSAP skill for the core API — gsap.to(), from(), fromTo(), easing, duration, stagger, defaults, gsap.matchMedia() (responsive, prefers-reduced-motion). |
| `gsap-frameworks` | Official GSAP skill for Vue, Svelte, and other non-React frameworks — lifecycle, scoping selectors, cleanup on unmount. |
| `gsap-performance` | Official GSAP skill for performance — prefer transforms, avoid layout thrashing, will-change, batching. |
| `gsap-plugins` | Official GSAP skill for GSAP plugins — registration, ScrollToPlugin, ScrollSmoother, Flip, Draggable, Inertia, Observer, SplitText, ScrambleText, SVG and physics… |
| `gsap-react` | Official GSAP skill for React — useGSAP hook, refs, gsap.context(), cleanup. |
| `gsap-scrolltrigger` | Official GSAP skill for ScrollTrigger — scroll-linked animations, pinning, scrub, triggers. |
| `gsap-timeline` | Official GSAP skill for timelines — gsap.timeline(), position parameter, nesting, playback. |
| `gsap-utils` | Official GSAP skill for gsap.utils — clamp, mapRange, normalize, interpolate, random, snap, toArray, wrap, pipe. |
