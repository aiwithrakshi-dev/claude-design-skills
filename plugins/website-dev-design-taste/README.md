## Install

- **claude.ai or desktop app:** download [website-dev-design-taste.plugin](https://github.com/aiwithrakshi-dev/claude-design-skills/raw/main/dist/website-dev-design-taste.plugin), then go to Customize > Plugins > Add > Upload plugin.
- **Claude Code (2.1.275 or later):** `/plugin install website-dev-design-taste --marketplace aiwithrakshi-dev/claude-design-skills`
- **Claude Code (any version):** `claude plugin marketplace add aiwithrakshi-dev/claude-design-skills` then `claude plugin install website-dev-design-taste@aiwithrakshi`
