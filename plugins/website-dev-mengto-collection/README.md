- **Claude Code (2.1.275 or later):** `/plugin install website-dev-mengto-collection --marketplace aiwithrakshi-dev/claude-design-skills`
- **Claude Code (any version):** `claude plugin marketplace add aiwithrakshi-dev/claude-design-skills` then `claude plugin install website-dev-mengto-collection@aiwithrakshi`
