## Install

- **claude.ai or desktop app:** download [website-dev-ux-product.plugin](https://github.com/aiwithrakshi-dev/claude-design-skills/raw/main/dist/website-dev-ux-product.plugin), then go to Customize > Plugins > Add > Upload plugin.
- **Claude Code (2.1.275 or later):** `/plugin install website-dev-ux-product --marketplace aiwithrakshi-dev/claude-design-skills`
- **Claude Code (any version):** `claude plugin marketplace add aiwithrakshi-dev/claude-design-skills` then `claude plugin install website-dev-ux-product@aiwithrakshi`

## Try these prompts

- Do a full design review of this checkout flow (usability, microcopy, dark patterns).
- Design the pricing page for my SaaS with three plans.
- Take my app idea from problem statement to a build-ready product spec.
