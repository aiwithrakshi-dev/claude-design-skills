## Install

- **claude.ai or desktop app:** download [website-dev-stageshow.plugin](https://github.com/aiwithrakshi-dev/claude-design-skills/raw/main/dist/website-dev-stageshow.plugin), then go to Customize > Plugins > Add > Upload plugin.
- **Claude Code (2.1.275 or later):** `/plugin install website-dev-stageshow --marketplace aiwithrakshi-dev/claude-design-skills`
- **Claude Code (any version):** `claude plugin marketplace add aiwithrakshi-dev/claude-design-skills` then `claude plugin install website-dev-stageshow@aiwithrakshi`

## Try these prompts

- Make an animated product demo of my invoicing app: a cursor creates an invoice and sends it.
- Build a bento grid of feature cards with mocked dashboard UI inside each card.
