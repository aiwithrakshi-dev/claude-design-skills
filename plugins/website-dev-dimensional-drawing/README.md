## Install

- **claude.ai or desktop app:** download [website-dev-dimensional-drawing.plugin](https://github.com/aiwithrakshi-dev/claude-design-skills/raw/main/dist/website-dev-dimensional-drawing.plugin), then go to Customize > Plugins > Add > Upload plugin.
- **Claude Code (2.1.275 or later):** `/plugin install website-dev-dimensional-drawing --marketplace aiwithrakshi-dev/claude-design-skills`
- **Claude Code (any version):** `claude plugin marketplace add aiwithrakshi-dev/claude-design-skills` then `claude plugin install website-dev-dimensional-drawing@aiwithrakshi`

## Try these prompts

- Make a dimensional drawing of my primary button component with all measurements.
- Create a spec sheet (anatomy drawing) of this pricing card.
- Turn that drawing into a 10-second motion film.
